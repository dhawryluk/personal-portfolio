# Derek Hawryluk – Professional Portfolio

Welcome to my professional portfolio!  
This project is a showcase of my skills, experience, and passion for front-end web development and thoughtful UI/UX design.

---

## 🚀 About the Project

This portfolio was built with **React** and **Tailwind CSS** using **Vite** for a fast, modern development experience.  
It features a clean, responsive design, custom branding, and a focus on accessibility and user experience.

### ✨ Features

- **Hero Section:** Eye-catching intro with custom logo and background imagery.
- **About:** My background, skills, and approach to web development.
- **Projects:** Selected works demonstrating my technical and creative abilities.
- **Skills:** Technologies and tools I use.
- **Contact:** Easy ways to get in touch.

---

## 🛠️ Tech Stack
